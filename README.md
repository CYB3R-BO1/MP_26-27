# Major Project 2026–27 — Research Discovery

Research workspace for selecting one defensible, experimentally testable AI-for-cybersecurity major project.

## Current phase: paper discovery

Seven members will each contribute **two 2026 research papers** (14 total). These are candidates, **not a finalized project proposal**. After reviewing submissions, the team will select a research problem, verify novelty against related work, then define a methodology and experiments.

**Selection priorities:** high-quality 2026 research; feasible experimental progress by **2026-12-31**; actual novelty and measurable security impact; meaningful AI engineering; manageable compute/public resources; two complementary group contributions (4 + 3 people). Prefer network security, but keep alternatives open. Avoid repeating federated/continual-learning and conventional graph-based IDS work.

## How to submit a paper

1. Copy `paper-discovery/TEMPLATE.md` to `paper-discovery/<your-name>/01-short-title.md` (then `02-short-title.md`).
2. Fill every section using original paper evidence; mark unavailable items **Not verified**, not guesses.
3. Link to primary paper, code, datasets, results, and close prior research.
4. Commit to your branch and submit a pull request for review. Avoid presenting a proposed extension as established novelty.
5. During the group review, apply the shared 1–5 rubric (nine criteria, maximum 45) and review critical feasibility risks separately from total score.
